# Редактор: режим 

## 1. Почему было плохо

Каждая клавиша уходила в VM, и VM сразу переразбирала текст и печатала его в каноническом
виде (решение 2026-09-29 «проекция сразу каноническая»). Отсюда все жалобы:

| Симптом | Причина |
|---|---|
| сами вставляются `;` | каждая строка сразу становится узлом, а `;` ставит печать |
| пробел не работает | пробелы ставит печать: лишний набранный пробел исчезает |
| пропадают строки | пустые строки сводятся к канону; недописанная строка, распавшаяся на части, становится одной дырой |
| не работают ↑/↓ | VM знает только ←/→/Home/End |
| нет информации по наведению | в протоколе такого запроса нет |
| нет подсказок по `syntax` | дополнение знает только имена |

Как вести набор, у автора прямо не сказано — это решения пользователя (2026-10-12):
текст набирается как есть, разбирается то, что есть, проверка — по паузе в 1 с;
**набор — в VM** (клавиши, как раньше); **канон — при уходе из элемента модуля**.

## 3. Модель

Текст представления состоит из двух видов кусков:

- **принятый** — каноническая проекция AST;
- **черновик** — текст одной единицы ровно так, как набран. Это тоже проекция: VM
  разбирает его, и раскладка единицы строится не печатью, а по местам узлов в набранном
  тексте (`where` из разбора). Поэтому DOM остаётся деревом AST и в черновике: метки,
  наведение, дополнение и переход работают по узлам, а текст не меняется.

**Единица черновика** — элемент модуля целиком, с пустыми строками и разделителем перед
ним (решение автора: канон — при уходе из элемента модуля). Правка, задевающая
соседний элемент (выделение через границу), расширяет черновик на него: «сломаны
скобки — берутся внешние». Разбирается черновик целиком — он мал,
а обновление окну всё равно самое узкое.

## 4. Как сделано (шаг 1–2)

- **Черновик** — элементы модуля, которые правят (в представлении функции — она сама):
  `editor_view::draft`. Первая правящая клавиша открывает его; правка, задевшая соседний
  элемент, расширяет.
- **Каждая клавиша** правит текст черновика и разбирает его целиком
  (`parser::parse_draft`): непарная скобка — по отступу (§4.1); инструкция без `;`, за
  которой с новой строки на том же отступе идёт следующая, — дыра своей строки
  (`end_unfinished_by_lines`); незакрытая строка — дыра своей инструкции.
- **Раскладка** — по местам узлов в набранном тексте (`printer::verbatim`); сырой
  блок, `native` и дыра — листья с текстом как написан.
- **id узлов** — у совпавших по месту и виду старые (`graft`): метки, курсоры других
  клиентов и слои переживают набор. Обновление — самого узкого изменившегося поддерева.
- **Пауза 1 с** (таймер io_uring): `check`, элаборация ct-кода, метки — всем.
- **Канон** — курсор вне элемента, Escape, Ctrl+S, F5/F6, F12, Ctrl+P, другое
  представление: проекция печатает элементы, пустые строки черновика — раскладкой
  (`blank`), комментарии после последнего элемента своими строками — следующему.
  Курсор выравнивается по тексту (`align`).
- **Как в обычном редакторе:** ←→↑↓ (колонка запоминается), Home — к коду, второй
  раз — к началу строки, Ctrl+←/→ по словам, PageUp/Down, Ctrl+Home/End, Shift —
  выделение, протяжка и Shift+щелчок мышью, двойной щелчок — слово, тройной — строка,
  Ctrl+A/C/X/V (без выделения — строка), Ctrl+Z/Y внутри черновика, Tab/Shift+Tab,
  Enter с отступом строки (после `{` — глубже, между `{}` — две строки), `}` в отступе
  — на уровень меньше, Backspace в отступе — до колонки отступа, IME.
- **Несколько клиентов:** элемент в чужом черновике не правится («элемент правит
  другой клиент»); остальные видят принятое состояние канонически.

## 5. Осталось

- **Наведение** `c_hover {узел}` → `s_hover`: типы по экземплярам, значения в слоях,
  ошибка с трейсом, сигнатура объявления, комментарий перед ним.
- **Форма конструкции.** Набрано имя конструкции или записи `syntax` — подсказка формы
  (`when(c, expr yes) otherwise(expr no)`); внутри скобок вызова — сигнатура с текущим
  параметром. Источник — объявления и записи `syntax` в контексте места.
- **Журнал**: черновик — одной записью (сейчас каждая клавиша — импорт текста).
- **Откат принятого** — по журналу базы (сейчас Ctrl+Z — внутри черновика).
